# АтомПросвет

Образовательный веб-тренажёр-симулятор пульта управления атомной
электростанцией для школьников и студентов. Подробное техническое
задание — в [docs/TZ.md](docs/TZ.md).

## Быстрый старт перед выступлением

Поднять на любом ноутбуке за минуту:

```bash
npm install
npm run dev
```

Открыть адрес из терминала (обычно `http://localhost:5173`) в браузере.

На стартовом экране — кнопка **«📖 Как играть — подробный гайд»**:
пошаговое объяснение пульта, управления, нештатных ситуаций, очков и
достижений. Стоит прочитать один раз перед первой сменой — дальше
тренажёр проходится самостоятельно, без подсказок со стороны.

Дальше — выбор сложности (Лёгкий / Обычный / Сложный, влияет на то, как
рано и как часто начинаются нештатные события) и две кнопки запуска:

- **«Начать смену»** — обычная смена, 5 минут.
- **«🎤 Демо-сценарий (≈2.5 мин, для питч-сессии)»** — тот же тренажёр,
  но ужатый по таймингу специально для короткого выступления (сложность
  на неё не влияет): первое нештатное событие приходит уже через
  ~10-15 секунд, события идут заметно чаще, а вся смена укладывается в
  2.5 минуты — гарантированно видно и спокойную работу станции, и
  нештатную ситуацию, и разблокировку достижения ещё до конца показа.

Кнопка **«⛶ Во весь экран»** (на стартовом экране и на пульте) переводит
страницу в полноэкранный режим — удобно для показа через проектор.

Если ближе к делу нет времени даже на `npm install` — заранее собранная
`npm run build` + `npm run preview` версия работает идентично и не требует
интернета после установки зависимостей.

## Стек

React + TypeScript + Vite, Tailwind CSS, Zustand, Recharts, Framer Motion, Vitest.

## Другие команды

```bash
npm run test      # unit-тесты движка симуляции (src/engine)
npm run lint       # ESLint
npm run format      # Prettier
npm run build        # production-сборка
npm run preview      # предпросмотр production-сборки
```

## Статус

Проект пройден по плану из docs/TZ.md, этапы 1-9:

1. Техническое задание и физическая модель реактора.
2. Каркас проекта и движок симуляции (`src/engine/`, unit-тесты).
3. Визуальный тёмный пульт управления с круговыми индикаторами и графиком.
4. Обучающий слой: подсказки, панель «Справка», экран «Факты».
5. Нештатные события с автогенерацией и нарастающей сложностью.
6. Геймификация: очки, 6 достижений, экран итогов смены со званием.
7. Анимированный стартовый экран, микро-взаимодействия (Framer Motion),
   проверено на разрешениях ноутбука (1366×768) и проектора (1920×1080).
8. Тестирование: полный игровой цикл (в т.ч. авария и штатное завершение
   смены по времени) пройден несколько раз, стресс-тест резких кликов и
   resize «на лету» — багов не найдено. `npm run build` + `npm run preview`
   проверены и работают чисто.
9. Демо-сценарий для питч-сессии (ускоренный тайминг событий, отдельная
   кнопка на стартовом экране), полноэкранный режим, эта инструкция.
10. Полноценный гайд «Как играть» на стартовом экране и на пульте,
    3 уровня сложности перед стартом смены.
11. Локальный рейтинг лучших смен (в браузере, top-10 по очкам) на
    экране итогов.
12. Углубление симуляции: расход топлива с ограничением мощности при
    критическом запасе, ручная аварийная защита (АЗ), 7-е достижение.
13. Понятный интерфейс: строка «что делать сейчас», подписи нормы под
    шкалами, прогресс смены, кнопки действий в тревогах, подтверждение
    опасных кнопок, тревоги сразу под шкалами на планшете.

## Реализовано

- Симуляция реактора: мощность (плавное изменение, без мгновенных
  скачков), температура, давление, охлаждение, интегральный уровень
  безопасности — с логически связанной, тестируемой физической моделью.
- Визуальный пульт: круговые индикаторы с цветовой индикацией и
  пульсацией в опасной зоне, график истории за 60 секунд, распределение
  выработки между городом и промышленностью.
- Обучающий слой: подсказки на каждом индикаторе, панель «Справка»,
  экран «Факты об атомной энергетике» (8 карточек, в т.ч. про БелАЭС).
- 4 нештатных сценария с автогенерацией по нарастающей сложности,
  всплывающими уведомлениями и звуковым сигналом.
- Геймификация: очки, 7 достижений с анимированными уведомлениями,
  экран итогов смены со званием («Стажёр» / «Оператор» / «Главный
  инженер смены»).
- Подсказки по ходу игры: цветная строка «что делать сейчас» (спокойно,
  подсказка, внимание, опасно), норма под каждой шкалой, прогресс смены,
  таймер с полосой в карточке тревоги и кнопка с конкретным действием.
- Расход топлива (ограничивает мощность при критическом запасе) и
  ручная аварийная защита (АЗ) — мгновенный останов ценой штрафа очков,
  в отличие от обычного плавного управления мощностью.
- Анимированный стартовый экран, демо-режим для презентации,
  полноэкранный режим, 3 уровня сложности.
- Гайд «Как играть» — пошаговая инструкция для тех, кто открыл
  тренажёр первый раз и хочет разобраться сам, без стороннего объяснения.
- Локальный рейтинг: топ-10 лучших смен сохраняется в браузере (localStorage)
  и показывается на экране итогов с отметкой нового рекорда.
- Доступность: зоны индикаторов показаны не только цветом, но и значком
  (! / ✕) — важно для людей с дальтонизмом; все анимации уважают системную
  настройку «Уменьшить движение» (prefers-reduced-motion).

## Идеи для развития после конкурса

- Интеграция реальных (или близких к реальным) данных БелАЭС —
  фактическая выработка, доля в энергобалансе — вместо условных цифр,
  для более достоверной образовательной ценности.
- Многопользовательский режим для класса: учитель видит показатели всех
  учеников на одном экране, сравнение результатов смены — превращает
  тренажёр в групповое занятие, а не только индивидуальную демонстрацию.
- Мобильная версия / адаптация под планшет для использования на уроке
  без компьютерного класса.
